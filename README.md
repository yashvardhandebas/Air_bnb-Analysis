# Airbnb Open Data Analysis

This repository contains the data cleaning and exploratory data analysis (EDA) for the Airbnb Open Data dataset.

## Datasets

To keep this repository lightweight, the raw and cleaned datasets are stored on Google Drive:
👉 **[Google Drive Dataset Folder](https://drive.google.com/drive/folders/1P2O6q6veUrosR-fwvXcfKsufHbpDVMBi?usp=drive_link)**

The folder contains:
- `Airbnb_Open_Data.csv` (Raw Dataset)
- `airbnb_cleaned_v2.csv` (Cleaned Dataset)

---

## Directory Structure

The project files have been organized into the following structure:

```text
├── Cleaning/
│   └── airbnb_eda_v2.ipynb          # Notebook for data loading, cleaning, and preprocessing
├── eda/
│   ├── airbnb_eda.ipynb              # Notebook covering structural checks and outlier analysis
│   ├── airbnb_eda_analysis.ipynb     # Notebook covering univariate, bivariate, and multivariate analysis
│   └── eda.ipynb                     # Draft exploration notebook
└── README.md
```

### Folder Explanations

- **`Cleaning/`**: Contains notebooks dedicated to preparing and preprocessing the raw data.
- **`eda/`**: Contains notebooks analyzing the dataset features, distributions, correlations, and key insights.
